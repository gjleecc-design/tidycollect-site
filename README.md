# 點滴相簿 TidyCollect — 支援與隱私權政策網站

這個資料夾只放網站需要的檔案，可以單獨上傳到 GitHub Pages（不要上傳整個 App 專案）。

- `index.html`：支援頁（簡介、畫面預覽、常見問題、聯絡方式）
- `privacy.html`：隱私權政策（中英文）
- `style.css`、`img/`：版面與畫面預覽

## 上傳到 GitHub Pages
1. GitHub → New repository，名稱建議 `tidycollect-site`，選 **Public**。
2. 把本資料夾裡的所有檔案（含 `img/` 與 `.nojekyll`）拖進倉庫，Commit。
3. 倉庫 Settings → Pages → Source 選 `main` 分支、`/ (root)`，儲存。
4. 1～2 分鐘後網址是 `https://你的帳號.github.io/tidycollect-site/`，隱私權政策是 `…/privacy.html`。

## 上傳前請確認
- **聯絡方式**：網站只放回報表單連結，沒有公開信箱。
- 畫面預覽目前是模擬器截圖（含示範照片），正式版要換成新截圖。
- iCloud 同步的畫面預覽已先拿掉；`privacy.html` 仍有 iCloud 段落（App 內有這個選用功能，政策要誠實說明）。
